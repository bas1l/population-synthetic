Population-Synthetic · Comparison Pipeline

Comparison metrics: a field guide

Every statistical metric the pipeline computes when it scores a synthetic population against a real one — each with a plain-language description, the formula in words, one clean worked example, and a purpose-built visual. No prior knowledge of the codebase assumed.

Population A — real / reference

The ground truth. E.g. the SCB-sampled Swedish population drawn from national statistics. Teal bars everywhere below.

Population B — synthetic

The population under test. E.g. LLM-generated personas. Ochre bars everywhere below. Every metric asks: how well does B reproduce A?

A quick mental model: families 1–3 ask increasingly demanding questions, and family 4 adds the strongest test of all — can a classifier tell the two populations apart? 1

Marginal metrics

One attribute at a time: does each field have the right distribution on its own? Think of it as comparing two bar charts.

Every metric in this family scores one attribute by aggregating over that attribute's own categories — the bars of its bar chart. The running example throughout is the education_level distribution:

1a · Total Variation distance

tv_distance

What it measures. The single most intuitive "how different are these two bar charts" number — the total probability mass you would have to move to turn one distribution into the other.

Formula in words. Take the absolute difference in proportion for each category, add them up, and halve the total.

TV = ½ · Σ |proportion_A(category) − proportion_B(category)|

How to read it. Ranges from 0 (identical) to 1 (no overlap); lower is better. This is the metric behind the TV-similarity radar — plotted as similarity = 1 − TV, so higher is better on the radar:

Deep dive — why halve the sum? Without the ½ you double-count the displaced mass (every unit that leaves one category reappears in another) and TV loses its clean 0-to-1 scale. See the ½-factor note.

1b · Max absolute proportion difference

max_diff

What it measures. The single worst category — the largest gap between A and B in any one bar. Where TV aggregates error across all categories, max_diff reports the biggest single one.

max_diff = max over categories of |proportion_A − proportion_B|

How to read it. 0 to 1, lower is better. Its job is to catch "mostly fine but one category is badly wrong" — a case TV can average away.

1c · KL divergence

kl_divergence

What it measures. An information-theoretic "surprise" — how many extra bits you waste, on average, encoding the synthetic distribution with a code built for the real one. It punishes B for putting probability where A has almost none more harshly than TV does.

D_KL(B ‖ A) = Σ p_B(c) · log₂( p_B(c) / p_A(c) ) (Laplace-smoothed)

Read each term as a log-ratio weighted by how often the category occurs in B: log₂(p_B/p_A) is the "surprise" for that category — zero when B and A agree, positive when B over-represents it, negative when B under-represents it — and the p_B(c) in front weights it by B's own frequency. The base-2 log is what puts the answer in bits: it is the extra bits per person you waste encoding B's data with a code built for A. Individual terms can be negative, but the total is never below 0 (Gibbs' inequality). Laplace smoothing (add 1 to every count) keeps an empty category from causing a divide-by-zero or an infinite result.

How to read it. 0 = identical; no upper bound, higher is worse. It is asymmetric — the code computes B relative to A. Best for ranking models, not as an absolute pass/fail.

Deep dive — the log-ratio & base 2. What each term means, why the base is 2 (bits vs nats), why terms can be negative yet the total never is, and how Laplace smoothing shifts the number. See the bits & log-ratio note.

1d · Chi-squared goodness-of-fit p-value

chi_sq_p

What it measures. A formal hypothesis test: could B's category counts plausibly have been drawn from A's distribution, or is the gap too big to be chance? It accounts for sample size — the same percentage gap is more damning with 1,000 people than with 10.

How it works. Scale A's proportions up to B's sample size to get expected counts, compare against B's observed counts via Σ (obs − exp)² / exp, and convert to a p-value.

Result: χ² large → p < 0.001 Flagged in the summary with a *

How to read it. A p-value in [0, 1], and its direction is the opposite of the distance metrics:

High p (> 0.05) → no significant difference → B matches A. Good. Low p (< 0.05) → significant divergence.
⚠ Caveat. With a tiny synthetic population (n < 5) chi-squared is unreliable and the report warns. And with very large n, even trivial differences read as "significant" — so read chi_sq_p alongside TV, never instead of it.
2

Joint distribution metric · legacy

Do two attributes relate to each other the same way in both populations?

2a · Joint chi-squared p-value

joint_chi_sq

What it measures. The marginals check each attribute alone. This checks whether two attributes co-vary the same way — e.g. is the age × education cross-tabulation consistent between A and B? A model can get every marginal perfect yet still pair young age with a doctorate too often; this is the first test that catches it.

How it works. For each configured pair, build a contingency table for A and for B, add them together, and run chi2_contingency on the combined table.

How to read it. A p-value; high = the joint structure is consistent, low = significant difference in how the two attributes co-vary.

This legacy test pools A and B into one table, so it is a coarse "are these distinguishable" signal. The newer grounded joint TV and Cramér's V delta give a finer, magnitude-based read on the same idea.
3

Individual coherence · legacy

Are individual synthetic people realistic — not just the aggregates?

3a · Coherence score

coherence.score

What it measures. A distribution can be right in aggregate while still containing impossible individuals (a 7-year-old with a PhD and full-time job). This scores the fraction of synthetic people whose combination of attributes actually occurs in the real population.

How it works. From A, build a lookup of the empirical (un-smoothed) probability of each combination of the coherence attributes (Swedish scheme: age_group × education_level × employment_status). For each synthetic individual, look up their exact combination: at or above the threshold → plausible; below it → flagged (its id, attribute values and probability recorded for inspection).

score = n_plausible / n_total_B

The threshold is the whole test. The Swedish scheme sets coherence_threshold = 0.001 — a combination must occur in at least 0.1 % of the real population to count as plausible (≥ 10 people in a real A of 10,000). Because the table is un-smoothed, a combination that never appears in A has probability exactly 0, so "flagged" splits into two zones:

How to read it. 0 to 1, higher is better — a bluntly interpretable "what fraction of my synthetic people are demographically possible." But a high score is cheap when the threshold is low (it mostly rules out the impossible, not the merely unusual), and it treats A as ground truth even though A is a finite sample — so read it alongside the threshold value and §4d's impossible/rare split.

Deep dive — the plausibility threshold. What the threshold really means, the two ways to be flagged, the missing-value trap, why the tuple stays small (curse of dimensionality), the "A is a finite sample" caveat, and how coherence relates to §4d. See the coherence-score note.
4

Multivariate / joint fidelity · new

The deepest checks — whole-profile and pairwise structure, not just the shape of each field.

4a · C2ST — Classifier Two-Sample Test

c2st.auc / p_value

What it measures. The single strongest overall fidelity test. If a machine-learning classifier cannot tell real profiles from synthetic ones, the synthetic data is statistically indistinguishable from real — the gold standard. If it separates them easily, something about the joint profile is off.

How it works. One-hot encode each whole profile; label real 0 and synthetic 1; balance the classes by subsampling (real usually vastly outnumbers synthetic) and repeat; train with cross-validation and measure ROC-AUC. Backend is cross-validated logistic regression (scikit-learn) or a numpy nearest-centroid / linear-MMD surrogate; a permutation test gives the p-value.

How to read it. AUC ≈ 0.5 → indistinguishable (best); AUC → 1.0 → trivially separable (worst). The p_value tests whether an AUC above 0.5 is real or noise — a high p is good (can't reject "indistinguishable"). The AUC uses the rank-based Mann–Whitney identity (identical populations give exactly 0.5); the p-value is an add-one permutation value (1 + #{perm ≥ observed}) / (1 + n_permutations), so it never hits 0 (floor ≈ 1/201). SCB tuning: folds=5, method="sklearn", seed=42; primitive defaults n_repeats=5, n_permutations=200.

Deep dive — how the test is built. One-hot encoding, class balancing (balanced_n = min(n_real, n_syn)), the Mann–Whitney AUC, the permutation p-value, and the sklearn-vs-MMD backends. See the C2ST note.

4b · Pairwise association fidelity — Cramér's V delta

association

What it measures. Whether the strength of association between every pair of attributes is reproduced. Cramér's V is a 0–1 measure of how strongly two categorical variables are related (0 = independent, 1 = one perfectly predicts the other). This computes V for each pair in both populations and reports how far apart they are.

How it works. For each pair, compute the bias-corrected (Bergsma) Cramér's V for A (v_real) and B (v_syn), then abs_delta_v = |v_real − v_syn|. Summarised by mean_abs_delta_v (average gap) and frobenius_norm (root-sum-of-squares, penalising a few large errors).

How to read it. abs_delta_v, mean_abs_delta_v, frobenius_norm are all ≥ 0, lower is better (0 = association structure perfectly reproduced). Unlike the joint chi-squared p-value, this gives a direction and magnitude — you see which pair is wrong and by how much (also exported to CSV). Note it scores every attribute pair (all 105 for the Swedish scheme), not just the configured joint pairs.

Deep dive — the V formula & the summaries. The full Bergsma bias-correction (φ², corrected row/column counts), why all 105 pairs are scored, and how mean_abs_delta_v vs frobenius_norm weight a single broken pair differently. See the Cramér's V note.

4c · Grounded joint total-variation distance

joint_fidelity.pairs

What it measures. The same TV idea as §1a, but on a two-attribute joint distribution — the total misplaced mass across the full x × y grid of a pair.

TV = ½ · Σ_cells |p_A(x, y) − p_B(x, y)|

How to read it. 0 (identical joint) to 1 (disjoint), lower is better. Returns NaN when either population has no individuals in the grid. The finer, magnitude-based complement to the legacy joint chi-squared p-value. Read the grounded flag first — only grounded pairs support a claim that the synthetic joint reproduces reality.

Deep dive — normalisation & grounding. The per-population normalisation, the NaN-means-"not measurable" rule, and the full SCB pair table (5 grounded vs 3 reference, with the audit basis for each). See the grounded joint-TV note.

4d · K-way combination plausibility

combination_plausibility.checks

What it measures. A generalisation of the coherence score to arbitrary k-attribute combinations, splitting failures into two severities instead of one pass/fail.

How it works. For each configured check (a tuple of k attributes + a threshold), build A's joint probability table over that tuple, then classify each synthetic individual:

How to read it. fraction_impossible and fraction_rare are ≥ 0, lower is better; fraction_impossible = 0 means every synthetic profile is at least possible in reality. NaN when B is empty. For the same tuple and threshold this is exactly the coherence score split by severity: fraction_impossible + fraction_rare = 1 − coherence.score.

Deep dive — the severity split. The exact three-way boundary rule (p ≤ 0 impossible / 0 < p < threshold rare / p ≥ threshold plausible), the fraction equations, and the count-for-count relationship to the §3a coherence score. See the k-way plausibility note.

The one trap to remember

The two p-value metrics (chi-squared GoF, joint chi-squared) and the C2ST p-value run opposite to the distances — for those, a high value is good (no detectable difference). Every distance / divergence / AUC metric is "lower is better."
