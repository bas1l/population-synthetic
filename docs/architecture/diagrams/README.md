# Architecture diagrams

Workflow / DAG diagrams for the project's two distinct population-generation
families. Each family lives in its own subfolder and is regenerated by its own
script. Every diagram ships as a vector (`.svg`) and a raster image (`.png`).

| Subfolder | What it covers | Source layer | Generator |
|---|---|---|---|
| [`real/`](real/README.md) | **Real population generation** — per-country conditional chained sampling from real national statistical APIs (SCB / SSB / ISTAT+Eurostat). One DAG per country. | `src/population_synthetic/generators/real/{sweden,norway,italy}/` | `scripts/dev/draw_generation_dags.py` |
| [`synthetic_strategies/`](synthetic_strategies/README.md) | **LLM identity-generation strategies** — the five configurable per-field strategies (`all_pick`, `all_pick_dag`, `all_generate_pick`, `all_generate_evaluate_pick`, `all_generate_evaluate_random_pick`): their category dependency DAG + per-field method pipeline. | `src/population_synthetic/generators/synthetic/identity_generator_configurable.py` | `synthetic_strategies/render_strategy_diagrams.py` |

The two families are complementary halves of the pipeline: `real/` diagrams
show how the **real** population is sampled from real statistics, and
`synthetic_strategies/` diagrams show how **LLM-generated** persona identities
are produced — the comparison pipeline scores the latter against the former.
