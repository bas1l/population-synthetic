The `config/` inventory: what each config tree holds and which code reads it.

- **Seed manifests:** `config/synthetic/manifests/` -- YAML files that bundle all identity generation settings (provider, model, mode, config, strategy, parallel params) into a single file. Loaded via `--manifest` flag. CLI args override manifest values when both are provided.
- **Simulation configs:** `config/synthetic/simulation_configs/` -- per-attribute `categories` schema + locale `instruction` system prompt for configurable mode. Strategy definitions are single-file yamls under `config/synthetic/axes/strategies/` (see [Axis composition](axis-composition.md)).
- **SCB API cache:** `config/database/caches/scb/` (git-ignored)
- **SSB API cache:** `config/database/caches/ssb/` (git-ignored)
- **Eurostat API cache:** `config/database/caches/eurostat/` (git-ignored)
- **ISTAT API cache:** `config/database/caches/istat/` (git-ignored)
- **Category label mappings:** `config/mapping/{scb,istat}/` -- the unified symmetric comparison config: one JSON file per comparison attribute (filename stem == top-level key) declaring `values`/`real`/`synthetic`, plus an `_index.json` master (`attribute -> filename` in axis order -- attributes only). The loader (`load_mappings`/`load_index` in `analysis/mapping/real_mapper/mappings.py`; `analysis/mapping/normalizer.py` re-exports `load_mappings`) merges every `*.json` in a country directory into a single dict keyed by stem (it also still accepts a single monolithic file). Both mapper sides and the comparison scheme are driven entirely by this config -- see [Comparison & mapping](comparison-mapping.md) and each dir's `README.md`. The cross-attribute comparison statistics (`joint_pairs`/`coherence_attributes`/`coherence_threshold`) are **not** here -- they live in `config/analysis/fidelity/{scb,istat}.json` (see **Run-analytics defaults** below / `analysis/fidelity/scheme.py`). (`config/mapping/ssb/` is legacy Norway config, not wired into the comparison scheme mechanism.)
- **Axis configs:** `config/synthetic/axes/models/`, `config/synthetic/axes/strategies/`, `config/synthetic/axes/countries/` -- YAML files composable via `--model-id`, `--strategy-id`, `--country-id`. A country YAML carries `id`, `label`, `parameters.config` (pointing at a simulation config JSON), plus `parameters.reference` (real-population path; the YAML key itself is unrenamed pending a follow-up config-layer rename) and `parameters.mappings` (mappings dir) consumed by the comparison pipeline's `analysis/utils/country_config.py`. `swedish` -> `simulation_config_004_swedish_generative.json`, `italian` -> `simulation_config_005_italian_generative.json`; each simulation config carries a locale-specific `instruction` system prompt and per-attribute `categories`
- **Experiment defaults:** `config/synthetic/experiment_defaults.yaml` -- base parameters including `output_base` path
- **Analysis registry:** `config/analysis/analysis_registry.yaml` -- the single source of truth for the analysis layer: `stage_dir` (`03_Analysis`) plus one entry per process mapping its **canonical id** -> `{label, description, folder, script, dispatch}` (optional `legacy_folder` for back-compat reads). The id is simultaneously the registry key, the GUI workflow task key, and the `03_Analysis/` output-folder name. Loaded fail-fast by `analysis/utils/registry.py` (missing file / missing required key / unknown id raises), which exposes `get_process`, `analysis_output_dir(id, base, *, for_read=False)`, `resolve_output_base`, and `ANALYSIS_STAGE_DIR`; consumed by BOTH the analysis scripts and the GUI workflow model (`WorkflowConfigModel.get_task_meta`). The `mapping` entry sets `folder: mapping` with `legacy_folder: mapped` so readers fall back to any legacy on-disk `mapped/` until re-mapped.
- **Comparison targets:** `config/analysis/comparison_targets.yaml` -- the explicit completeness list consumed by the map stage (`scripts/analyze/map_populations.py`). `targets:` is a list of entries, each either a plain manifest-path string (country inferred from the simulation-config filename) or a `{manifest, country}` mapping (explicit country override). The map stage processes only these targets -- it does not scan disk.
- **Run-analytics defaults:** `config/analysis/analyze_defaults.yaml` -- `output_base` plus filename/verbosity defaults for `analyze_run.py` / `compare_run_analytics.py` (the `03_Analysis/run_analytics/` folder names themselves now come from the analysis registry above): per-run analytics land in `{output_base}/03_Analysis/run_analytics/{slug}/` and cross-run comparison in `.../run_analytics/_comparison/`
- **Model-ranking provider hosting:** `config/analysis/model_ranking/provider_hosting.json` -- a `{"providers": {provider -> "local"|"hosted"}}` map grouping each identity-generation provider (`model_config.provider` on the model axis YAMLs: `ollama`, `claude`, `gemini`, `openrouter`, `openai_compat`) into a hosting/provenance class (`ollama` -> `local`, the rest -> `hosted`). Loaded by `analysis/model_ranking/hosting.py` and embedded at `metadata.model_hosting` in the performance JSON so the manuscript tables can encode provenance by hue. Every provider must appear here -- an unknown provider fails loudly (no default class), per the fail-fast rule.
- **Model pricing table:** `config/analysis/model_pricing.yaml` -- the single source of truth for the `generation_metadata` cost model, consumed by `analysis/generation_metadata/pricing.py::load_pricing_table`. USD per 1,000,000 tokens, keyed by the model **axis id** (the same id used in run slugs / `discover_axis_values("models")`) so the join to a generation combo is exact: `models: {<axis_id>: {in: <price>, out: <price>}}`, with top-level provenance stamps `observed_date`, `source`, and `currency` carried verbatim into the analysis JSON. `ollama_*` models are priced at a genuine `0`. The prices are a static, dated snapshot (not fetched live); rows carry `[VERIFY]` / "effective/discounted" comments to check before publication use. Loaded fail-fast (missing file / missing required top-level key / empty `models` / non-numeric or negative rate raises); cost is `None` (not `0`) when a persona has no token telemetry, and a model that HAS tokens but no pricing entry raises loudly (`PricingTable.get`) rather than defaulting.
- **Method-comparison figure config:** `config/analysis/method_significance/comparison.json` -- drives the method-comparison significance figure/table emitted by `analyze_method_significance.py`. `pairs_mode` (one of `allowed_pairs_modes`: `adjacent` (default), `all`, `vs-baseline`, `significant-only`) selects which method pairs get a significance bracket; `star_thresholds` is the p-value -> star-symbol cutoff list (matched smallest-`max_p` first, first match wins) and `ns_symbol` the non-significant label (GraphPad/Prism convention). Loaded fail-fast by `analysis/method_significance/builder.py::load_comparison_config` (missing file / unknown `pairs_mode` / malformed shape raises); it knows nothing about models, countries, or matplotlib.
- **GUI config:** `config/gui/menu.yaml` + `config/gui/flows/*.yaml` -- the catalogue and per-flow round-trip YAML for the Flow Runner GUI (`gui`; see [gui Flow Runner](../development/gui.md))
